# AEROVA provenance and release notes

The final application was aligned during development with current public Indian Government, airline and OTA web material. Live page values are not hardcoded into the official index; the collector layer acquires them at runtime only where public/authorized access is permitted.

MoSPI's January 2026 release introduced CPI base 2024=100, and the current MoSPI FAQ states the current CPI base year is 2024=100.

DGCA publishes aviation statistics and uses a Tariff Monitoring Unit for airfare monitoring. For policy publication, the exact DGCA TMU traffic/benchmark export used by the deployment must be retained and hashed alongside the release.
